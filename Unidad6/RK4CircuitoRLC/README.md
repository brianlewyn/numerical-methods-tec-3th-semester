# RK4 Circuito RLC

Implementación en Java del método de Runge-Kutta de 4to orden vectorial
para resolver la respuesta libre de un circuito RLC serie.

## Sistema resuelto
```
y1' = y2
y2' = -0.4*y2 - y1
Y(0) = [1.0, 0.0]
```

## Requisitos
- JDK 8 o superior
- Versión al crear el código (java 27 2026-09-15)

## Clonar
```
git clone https://github.com/brianlewyn/numerical-methods-tec-3th-semester.git
cd numerical-methods-tec-3th-semester
```

## Compilar
```
javac Unidad6/RK4CircuitoRLC/*.java
```

## Ejecutar
```
java Unidad6.RK4CircuitoRLC.Main
```
